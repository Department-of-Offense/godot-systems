# Prototyping (`dof_prototyping`)

Greybox builders: a trooper unit and a battlefield with ground, sun, sky and cover, all made in code.

**Depends on:** dof_combat dof_navigation dof_units

For tests and early prototypes: `Prototype.CreateTrooper(name, team, color)` and `Prototype.BuildBattlefield(root)` (bakes a navmesh by default; pass `navigation: false` to skip). Replace with authored scenes once art exists.
